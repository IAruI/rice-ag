{{ 'ก่อนผสมเอง' if th else 'Before you blend' }}

{% if th %}
  • ปุ๋ยผสมให้ธาตุอาหาร N-P-K ตามสูตรเท่ากัน แต่ปุ๋ยสูตรสำเร็จจากโรงงานบางชนิดมีธาตุอื่นด้วย เช่น กำมะถัน หรือมีเม็ดปุ๋ยที่สม่ำเสมอกว่า
  • ยูเรียดูดความชื้นง่ายเมื่อผสมกับแม่ปุ๋ยอื่น ควรผสมใกล้วันใช้ และเก็บในที่แห้ง
  • ผสมให้เข้ากันดีบนพื้นที่สะอาด เม็ดปุ๋ยขนาดต่างกันมากจะแยกตัวเมื่อหว่าน
  • วิธีคิด: DAP ให้ฟอสเฟตทั้งหมดและไนโตรเจนบางส่วน ยูเรียเติมไนโตรเจนที่เหลือ โพแทสให้โพแทสเซียม ส่วนที่เหลือคือสารตัวเติม
{% else %}
  • A blend gives the same N-P-K, but some factory compounds also carry other nutrients such as sulfur, or have more even granules.
  • Urea picks up moisture once mixed with other straights: mix close to when you apply, and keep it dry.
  • Mix thoroughly on a clean floor; granules of very different sizes separate when spread.
  • How it is worked out: DAP supplies all the phosphate and some nitrogen, urea tops up the nitrogen, potash supplies the potassium, and filler makes up the weight.
{% endif %}
